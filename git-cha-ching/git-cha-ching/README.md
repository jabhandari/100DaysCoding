# git-cha-ching

`git-cha-ching` plays a notification sound when a Git push completes successfully in VS Code.

## Features
--test
* Plays a satisfying cha-ching sound after a successful Git push.
* Works with VS Code's built-in Git integration.
* Lightweight, no configuration required.

## Installation

1. Install the extension in VS Code.
2. Open a folder containing a Git repository.
3. Push changes using the Source Control view or the integrated terminal.

## Usage

When `git push` completes successfully, the extension will play the sound automatically.

## Extension Settings

This extension does not expose any custom settings yet.

## Known Issues

* The extension only triggers for Git push operations recognized by VS Code.
* Sound playback depends on your operating system and audio configuration.
